# Design Thinking Module 4 : Prototype

**POV ( Point Of View ):** How to fix software vulnerabilities more productively, with less human friction ?

Context: Machines already handle vulnerability discovery, but fixing still requires human intervention and verification. Corporations dedicate whole teams to finding and fixing newly discovered vulnerabilities. As AI models advance, critical vulnerabilities are surfacing faster than ever. Putting pressure on a fix process that still depends on people to keep pace.

**HMW ( How might we ? ):** How might we fix cyber vulnerabilities with less human intervention, so engineers can focus on meaningful, high cognitive work?
